# Historical reference: previous bot_ai-agent project

Last reviewed: 2026-07-25.

This file is retained only as historical context for a previous Telegram and
telephony-oriented project. It is **not** an implementation guide or source of
truth for AI Lead Pipeline.

Reusable ideas from that project are limited to FastAPI/SQLAlchemy setup,
idempotent webhook handling and a lightweight operator UI. Telegram, AI calling,
SIP, Zadarma and ElevenLabs are not Release 1 dependencies and must not be
reintroduced into the first-customer workflow without a separate approved
product, privacy and compliance decision.

Use [ARCHITECTURE.md](ARCHITECTURE.md),
[DEVELOPER_HANDOFF.md](DEVELOPER_HANDOFF.md), and
[TECHNICAL_MARKETER_HANDOFF.md](TECHNICAL_MARKETER_HANDOFF.md) for current work.
